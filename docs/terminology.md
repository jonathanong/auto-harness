# Terminology

Canonical vocabulary for UI copy, nav labels, docs, and `data-pw` selectors. When naming something new or renaming something existing, check here first — and update this file when the vocabulary changes.

The short version: **a "Host" runs "Sessions".** Never call either one an "agent" — the identity, env vars, CLI, and wire protocol all say "host"/"daemon" too, not just the UI copy.

---

## UI-facing terms

| Term                 | Meaning                                                                                                                                                                                                                                                                                                    | Where it shows up                                                                                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Host**             | A machine/daemon that registers with the control plane (identified by `hostId`), can be online/offline, drained, and owns host inventory.                                                                                                                                                                  | Control plane `/hosts` page; "Add host", "Drain"                                                                                                                           |
| **Session**          | A single Claude/Codex/etc. CLI invocation running against a worktree on a host. This is what people colloquially call "an agent" — in this codebase it is always a **session**, never an agent.                                                                                                            | `/sessions`, session status, logs                                                                                                                                          |
| **Concurrency ID**   | An optional, globally exact identity for an active session. It is both an idempotency key for repeated creates and a durable lock preventing overlapping manual or scheduled runs. Terminal sessions release it for retry.                                                                                 | Session/schedule create forms, API `concurrencyId`, run history                                                                                                            |
| **Repository**       | A git repo registered in the control-plane catalog, optionally with a host path attached.                                                                                                                                                                                                                  | `/repositories`                                                                                                                                                            |
| **Worktree**         | A git worktree under a repository on a specific host, where sessions actually run.                                                                                                                                                                                                                         | `/worktrees`, worktree detail pages                                                                                                                                        |
| **Host inventory**   | The repositories + worktrees + attached provider accounts (with per-repo/per-worktree enable/command overrides) configured for a given host. It also carries audited Host daemon update settings when updates are managed from the control plane.                                                          | Host pane Repositories/Settings pages (nested worktrees), control-plane Host Advanced tab, repository/worktree detail pages' Provider accounts tab, "Add repository" modal |
| **Provider**         | A global catalog entry for an AI CLI vendor (e.g. `claude`, `codex`, `grok`), with a default Command.                                                                                                                                                                                                      | `/providers`, `/providers/[id]`                                                                                                                                            |
| **Provider Account** | A specific account of a Provider (e.g. "claude — jonathanrichardong@gmail.com"), attached to one or more hosts. Provider targets draw from the healthy attached account pool; accounts are never direct session/schedule targets. A cooldown is global across every host attachment (5 hours by default).  | `/providers/[id]` Accounts tab, host/repository/worktree detail pages' Provider accounts tab                                                                               |
| **Command**          | A global catalog entry: a named, fixed `argv` (never a free-form shell string). Either owned by a Provider (reached only via that provider's accounts) or standalone (`providerId: null` — runs ungated on any worktree).                                                                                  | `/commands`, `/commands/[id]`, session/schedule create forms                                                                                                               |
| **Target**           | The primary routing reference on a session or schedule: `{ providerId }` selects the provider's healthy account pool, while `{ commandId }` selects that exact command (and its provider pool when provider-owned). `fallbacks` is an ordered list of additional Targets.                                  | Session/schedule forms and details                                                                                                                                         |
| **Queue TTL**        | The absolute amount of time a queued session may wait for capacity. It defaults to 8 days (`691200` seconds), is not reset by fallback attempts, and ends in `queue_expired`.                                                                                                                              | Session/schedule forms and queue status                                                                                                                                    |
| **Priority**         | A session's numeric queue urgency. Higher values are assigned before lower values; the UI constrains manual input to 0–100.                                                                                                                                                                                | Session create form and session lists                                                                                                                                      |
| **Required labels**  | Worktree capabilities that all must be present before a session can be assigned. No required labels means any worktree for the repository may run it.                                                                                                                                                      | Session create form and session lists                                                                                                                                      |
| **Session usage**    | CLI-authoritative, provider-neutral counters reported for one execution attempt. Auto Harness attributes records from the assigned route, never derives them from prompts or logs, and may show an optional operator-configured cost in integer micros; it does not bill or fetch vendor prices.           | Session detail usage summary and usage read API                                                                                                                            |
| **Command profile**  | _Removed_ — the old flat, host-scoped `argv` map used for session targeting before Provider/Provider Account/Command existed. `HostInventory` no longer carries a `commandProfiles` field; use **Command** instead.                                                                                        | n/a (superseded)                                                                                                                                                           |
| **Host pane**        | The **debug-only** per-host local UI (`services/host-pane`) for inspecting that host's inventory — status, repositories, worktrees, sessions. Operators should use the control plane; this pane has no login. Provider accounts show there read-only; attach/detach/override happens on the control plane. | `services/host-pane`, port 7422                                                                                                                                            |
| **Settings**         | Global control-plane configuration, split into Account, User accounts, Service accounts, and Slack pages. Slack settings are restricted to an unscoped admin; secret values are write-only and never displayed. Host Offline is an optional Slack notification for stale/offline hosts.                    | Control plane `/settings` (redirects to `/settings/account`); `nav-settings`, `nav-user-accounts`, `nav-service-accounts`, `nav-slack`                                     |
